## 왜 감사했나

아바타 생성 절차를 `orbit-avatar` 스킬로 표준화하면서, **검증 스크립트가 QA의 근간**이 됐다.
직전에 그 스크립트가 비율 드리프트(롱다리)를 `off-band`로 flag했는데도 "측정 흔들림"이라 넘긴
사고가 있었다(→ 신뢰 교훈 메모리 `feedback-trust-own-checks`). 그래서 **가드레일 자체를
편향 없이 독립 감사** 받는 게 필요했다. Codex(read-only) + Fable 5(합성 PNG로 실증) 동시 투입.

## 두 감사가 합의한 진짜 버그 (전부 수정됨)

## 두 감사가 "견고하다"고 확인한 것

- **PNG 디코더 코어 정확** (IHDR·다중 IDAT·필터 0–4·Paeth·stride) — 캐논 베이스가 문서값 43.0%/0.58로 정확 디코드.
- **투명 체크 신뢰 가능.**
- 인용된 에셋 수치 전부 일치 (red recolor 제외), 참조 경로 전부 존재, antenna/40px 교훈이 `extract.sh`와 실제로 일치.

## 남은 한계 (구조적 — 문서에만 반영, "수정"으로 안 됨)

- **텍스트→이미지는 확률적·비합성적.** 재생성/리포즈마다 이미지 전체를 재합성 → **비율이 목표를 중심으로 진동**(실측: 40.6% ↔ 51% 오갔음). 프롬프트 정밀도에 천장이 있어 **가이드라인 다듬기는 수익 체감**.
- **결론: 픽셀-정확 일관성은 2D 생성기에서 불가.** 진짜 일관성은 **3D 베이스 하나를 확립하고 헬멧·옷·색만 교체(같은 지오메트리 재사용)** 하는 레이어에 속함 → 비율=고정 지오메트리=드리프트 불가.
- **채택한 운용 철학:** 밴드 안(≈42–46%) 미세 비율 변동은 **결함이 아니라 "손맛/매력"으로 수용**(가족감 = 공유 스타일·얼굴·팔레트·실루엣, 픽셀-동일 아님). 단 **마감·색(무광·팔레트·적십자 등 브랜드)은 고정.** 검증 게이트 = "매력의 밴드 지킴이"(이상치만 리젝).

## 검증 방식(재현)

`python3 .claude/skills/orbit-avatar/scripts/verify-avatar.py <파일...>` — exit 0=전부 통과, 1=하나라도 실패.
실측: 가족 9장 → ALL PASSED(exit 0); 합성 그림자 디스크 → FAIL(exit 1). **숫자 통과 후 반드시 눈으로도 확인**(마감·색·포즈는 숫자로 안 잡힘 — 도그푸딩 중 의사 스크럽 웨더링·검은 십자·롱다리를 눈으로 잡음).
