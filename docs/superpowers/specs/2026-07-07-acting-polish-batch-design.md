# 연기 폴리시 배치 (②a 후속 5종) — 설계

날짜: 2026-07-07
상태: 설계 확정 (유저 승인), 구현 전
선행: `2026-07-07-avatar-acting-design.md` (슬라이스 ②a). 이 배치는 ②a의 시각 품질·라이브 엔진 공존 수정 5종.

## 배경 (당일 실측에서 나온 것들)

- 실작업 승인 게이트 실험 + 유저 관찰에서: 대기 강조 부재, 말풍선 붕뜸, 24자 잘림("코멘…"), 서성임이 "배회"로 읽힘(부산스러움), **언프리즈 시 부동자세 글라이딩**(엔진 이동 × 연기 오버라이드 충돌)이 확인됨.

## 5종 명세

### ① ⏸ 대기 시각 강조 — 앰버 글로우
- `IsoCharacter`에 `awaiting?: boolean` prop 추가. true면 발밑 글로우를 시안(0x22d3ee/0x38e6ff) → **앰버(0xffb454/0xffd28a)**로, `Pulse` 주기 1900ms → **2600ms**(느긋한 숨).
- Player가 `direction?.kind === 'awaiting_approval'`을 넘김.
- 근거: Company OS PRD 상태 색상 규칙 "Waiting Approval = 주황"과 색 언어 일치.

### ② 말풍선 붕뜸 보정
- `SpeechBubble.tsx` 상수: `TAIL_TIP_Y` -238 → **-198**, `PANEL_BOTTOM_Y` -252 → **-212** (40px 하강).
- 이유: 스프라이트 PNG 상단 투명 여백 때문에 보이는 머리끝과 말풍선 간격이 과대 → 남의 말풍선처럼 읽힘. 구조 버그 아님(말풍선은 캐릭터 컨테이너 내부) — 상수 튜닝.
- 검증: 전후 스크린샷 비교 (말풍선 꼬리가 머리 바로 위).

### ③ 잘림 완화
- Player의 연기 말풍선 `truncateBubbleText(summary, 24)` → **40**. 패널 wordWrap(420px)이 2줄로 처리 — 기존 스크린샷에서 2줄 가독성 확인됨.
- "이석현 영상에 코멘…" → "이석현 영상에 코멘트 발행?" 온전 표시.

### ④ 서성임 리디자인 — 걷고-서고 리듬 (유저: "부산스럽다")
- 기존: 6초 삼각파, 쉼 없는 왕복 ±1타일 → "배회"로 읽힘.
- 개선: **10초 주기 4구간** — 걷기(+x, 1.8s) → 서기(3.2s) → 걷기(-x, 1.8s) → 서기(3.2s). 진폭 **±0.5타일**(편도 0.5타일을 1.8s에 이동).
- 서 있는 시간 비율 64% — "책상 앞에서 가끔 들썩"으로 읽히게.
- 서기 구간: `speed 0`(유휴 프레임), facing은 직전 걷기 방향 유지.
- 여전히 `(name, now)` 순수 함수(절대시간 결정론·이름 해시 위상차 유지). 상수 4개(WALK_MS/DWELL_MS/AMPLITUDE/유도되는 주기)로 미세조정 가능.

### ⑤ 엔진 우선 규칙 — 라이브 공존
- 규칙: **엔진이 아바타를 움직이는 동안(`historicalLocation.speed > 0`)은 엔진이 완전히 이긴다** — 위치·facing·speed 모두 서버 값, 서성임 오프셋·부동자세 강제 미적용. 연기는 말풍선·하이라이트(·앰버)만 유지.
- 효과: 언프리즈 시 "부동자세 글라이딩" 소멸(걷기 애니로 자연 이동), Frozen에선 기존 ②a 동작 그대로.
- ②a 스펙의 전제(Frozen 전용)를 라이브 안전으로 확장하는 것. awaiting의 "부동"은 엔진이 세워둔 동안만 성립.

## 검증

1. **jest** — `pacingPose` v2 재작성 테스트: 결정론(같은 입력=같은 출력), |offset| ≤ 0.5, 한 주기 샘플링에서 **정지(speed 0) 비율 ≥ 60%**, 걷기 구간은 speed > 0이고 facing.dx가 이동 방향과 일치, 이름별 위상차. (기존 삼각파 테스트 3개는 이 명세로 대체.)
2. **시각** — Frozen에서 재생기 + Playwright: (a) working 아바타가 대부분 서 있고 가끔 이동 (b) ⏸ 아바타 발밑이 앰버 (c) 말풍선이 머리 바로 위 (d) 40자 말풍선 온전.
3. **회귀** — tsc·jest 전체·vite build.
